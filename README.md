# 旅費計算・金種表

最大20人分の旅費（電車賃・バス賃・宿泊費・日当・その他）を計算し、一人ごとの金種表と受領印つきの旅費受領名簿を作る、ブラウザだけで動くアプリです。

## 使い方

1. `index.html` をダウンロードして、ブラウザ（Chrome・Edge・Safari など）で開きます。
2. 件名・日付・行先・人数を入れます。
3. 一人ずつ、氏名・出発神社・電車賃（片道）・バス賃（片道）などを入れます。
   - 「往復」にチェックがあると、電車賃・バス賃を2倍にします。
   - 登録済みの出発地（南方八幡宮・山口駅・武氏八幡宮・代田八幡宮・山口大神宮・山口県神社庁）を選ぶと、下関駅までの片道運賃が自動で入ります。
4. 支給額は初期設定で1の位を切り上げ（10円単位）します。
5. 金種表で一人ごとの紙幣・硬貨の枚数を、右上で全員分の合計枚数を確認できます。
6. 旅費受領名簿をそのまま印刷すると、名簿だけがA4縦で印刷されます。

入力内容は、使っているブラウザの中にだけ自動保存されます。

| 出発 | 経路 | 電車賃 | バス賃 |

| 山口駅 | 山口駅→新山口駅→下関駅 | 1,520円 | 0円 |
| 武氏八幡宮 | 田万川地域生活バス（当面無料）→江崎駅→下関駅 | 2,640円 | 0円 |
| 代田八幡宮 | 柳井港駅→下関駅 | 2,640円 | 0円 |

## デスクトップ・ホーム画面に追加する

先に GitHub Pages を有効にしてください（Settings → Pages → Branch を `main`、フォルダを `/(root)` にして Save）。
数分後に https://jinjapriest.github.io/ryohi-keisan/ で開けるようになります。

- **パソコン（Chrome・Edge）**：上のアドレスを開き、アドレスバー右端のインストールのマーク、または画面内の「アプリとして追加」を押します。デスクトップとスタートメニューにアイコンができます。
- **iPhone・iPad（Safari）**：上のアドレスを開き、共有ボタン →「ホーム画面に追加」。
- **Android（Chrome）**：上のアドレスを開き、メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」。

一度開けば、電波のない場所でも使えます。
